# 线框图生成提示词

请根据以下规格生成一张可访问、响应式、可编辑的 HTML 语义框线 SVG。

## 任务与教学结论

生成一个用于 Chrome 扩展和商店展示的 JOBox 职位收集图标。读者必须一眼理解：职位沿蓝色向下箭头被收进 JOBox。

## 对象与可见文字

- 一个白底、黑色粗框的开放收集箱。箱体只有左右侧边和圆角底边，顶部中央保持开放。
- 箱体内部只显示一个对象标签，文字必须原样写为 `JOBox`，其中 `JOB` 大写、`ox` 小写。
- 一支蓝色向下箭头，位于箱体上方并进入顶部开口。
- 不出现外层应用方框、横向分隔线、小拉手、角标或其他装饰。

## 关系、方向与状态

- 蓝色箭头表示“职位流入 JOBox”的单向 `flow` 关系，方向严格自上而下。
- 箱体黑色实线表示一个已经存在、可用的持久容器。
- 不添加虚线、警告状态或其他无依据关系。

## 布局与阅读顺序

- 使用正方形画布和中心构图，阅读顺序为自上而下：箭头 → 箱体开口 → `JOBox`。
- 箭头垂直中心、箱体水平中心和文字中心必须共用同一中轴线。
- 箭头尖端进入箱体开口，但不得碰到左右端点；文字不得碰到箱体边界。
- 主体占据约 88% 画布，四边保留安全区；缩到 16px 时仍需辨认出箭头和开放箱体，32px 以上应能识别 `JOBox`。

## 视觉语法

- 画布和箱体内部使用纯白 `#FFFFFF`。
- 箱体框线和 `JOBox` 使用黑色 `#0A0A0A`。
- 蓝色 `#0348ED` 只用于向下箭头，明确表达收集方向。
- 使用 Geist、Inter 或系统无衬线字体，`JOBox` 使用粗体。
- 所有线条使用圆角端点和圆角连接；无渐变、阴影、滤镜、纹理、噪点、3D、科技感 UI 或装饰元素。

## SVG 技术约束

- 使用稳定的 `viewBox="0 0 128 128"`，不写固定像素宽高。
- 按“容器对象”和“流入关系”使用语义 `<g>` 分组，并添加 `data-boundary="job-box"` 与 `data-relation="flow"`。
- `JOBox` 必须保留为 `<text>`，不得转为路径，不使用 `<foreignObject>`。
- 所有 ID 使用 `job-collector-icon-` 前缀并保持唯一。
- 框线和箭头使用 `vector-effect: non-scaling-stroke`。
- 添加 `role="img"`、`aria-labelledby`、对应的 `<title>` 和 `<desc>`；描述必须说明箭头方向、箱体和保存职位的含义。

## 验收与输出

- 检查语义是否只表达“职位被收进 JOBox”，没有额外关系。
- 检查三者中心对齐、箭头与开口安全距离、文字与箱体边界无碰撞、所有内容均位于 viewBox 内。
- 检查纯白、黑色和语义蓝三色使用正确，并确认没有阴影、渐变或纹理。
- 检查 128px、48px、32px 和 16px 尺寸；128px 为商店图标，其他尺寸用于扩展。
- 检查 `<title>`、`<desc>` 与 `aria-labelledby` 一致。
- 输出完整、可编辑的 SVG，而不是位图或仅提供说明。
