# 线框图生成提示词

请根据以下规格生成一张可访问、响应式、可编辑的 HTML 语义框线 SVG。

## 任务与教学结论

生成一个用于 Chrome 扩展和商店展示的职位收集图标。读者必须在极小尺寸下一眼识别这是一个与 JOB 有关的工具，因此以超大白色 `JOB` 字标作为绝对主视觉，以顶部白色收入口暗示“收集”。

## 对象与可见文字

- 一个铺满正方形画布的黑色圆角底，使用非常轻微的圆角。
- 黑底上方中央放置一条短而宽的白色水平矩形，表示收入口；使用轻微圆角。
- 黑底下半部只显示一个白色粗体标签，文字必须原样写为 `JOB`，全部大写。
- `JOB` 使用 900 字重并尽可能占满可用宽度，同时保留最小安全边距。
- 不出现 `JOBox`、箭头、箱体轮廓、横向分隔线、小拉手、外框或其他装饰。

## 关系、方向与状态

- 不绘制箭头或关系线。顶部白条与 `JOB` 仅通过垂直排布形成“收入口位于职位容器上方”的无方向关联。
- 黑色方块表示稳定、持续可用的插件主体；不添加虚线、警告或临时状态。

## 布局与阅读顺序

- 使用正方形画布和自上而下的中心构图：白色收入口 → `JOB`。
- 白色收入口、`JOB` 字标和画布必须共用水平中心线。
- 收入口约占画布宽度的 38%，位于上方约 15% 处。
- `JOB` 占据画布宽度约 92%，位于下半部，视觉底边距约 15%。
- 缩到 16px 时仍必须辨认出黑色方块、顶部白条和 `JOB` 三个字母。

## 视觉语法

- 背景使用黑色 `#0A0A0A`。
- 收入口和 `JOB` 使用白色 `#FFFFFF`。
- 不使用蓝色、橙色、红色或其他颜色，因为最终图中没有方向、警示或错误语义。
- 使用 Geist、Inter 或系统无衬线字体，`JOB` 使用 900 字重。
- 无描边、渐变、阴影、滤镜、纹理、噪点、3D、科技感 UI 或装饰元素。

## SVG 技术约束

- 使用稳定的 `viewBox="0 0 128 128"`，不写固定像素宽高。
- 按“应用底板”“收入口”“JOB 标签”使用三个语义 `<g>` 分组，分别添加 `data-boundary="app-tile"`、`data-boundary="intake-slot"` 和 `data-boundary="job-label"`。
- `JOB` 必须保留为 `<text>`，不得转为路径，不使用 `<foreignObject>`。
- 所有 ID 使用 `job-collector-icon-` 前缀并保持唯一。
- 图形只使用填充，不使用描边或关系 marker。
- 添加 `role="img"`、`aria-labelledby`、对应的 `<title>` 和 `<desc>`；描述必须说明黑色底、白色收入口和白色 `JOB`。

## 验收与输出

- 检查语义是否只表达“JOB 工具与收集入口”，没有额外关系。
- 检查收入口与字标居中、二者不碰撞、字标不溢出、全部内容位于 viewBox 内。
- 检查只使用黑白两色，确认没有描边、阴影、渐变或纹理。
- 检查 128px、48px、32px 和 16px 尺寸；128px 为商店图标，其他尺寸用于扩展。
- 检查 `<title>`、`<desc>` 与 `aria-labelledby` 一致。
- 输出完整、可编辑的 SVG，而不是位图或仅提供说明。
