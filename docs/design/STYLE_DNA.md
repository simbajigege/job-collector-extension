# 风格 DNA

## 一句话

纯白、极简、留白、克制的技术doc式教程，文字为主，会有插图、视频。



## 必须

- 纯白背景：不要米色、暖灰、纸张纹理、渐变、阴影、噪点、复古纸感。

- 结构清晰

- 视觉指示明确

  

## 颜色

- 黑白灰：框线、结构、主要文字。

- 红色：重点、阻碍。\#FF3700

- 橙色：警示，提示。\#FE7E0F

- 蓝色：链接，指向性文字箭头。\#0348ED

  

  颜色要克制，宁可少不要多。



## 绝对不要

- 不要商业海报、落地图

- 不要煽动、鼓动性。

- 不要非常多的情绪。

- 不要可爱。

- 不要科技感 UI。

- 不要复杂背景、渐变、阴影、纹理。

  

## 审美方向

要简洁清爽。

不要可爱、幼稚、很复杂、死板、怪诞、创意。
