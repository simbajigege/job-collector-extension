| -------------- | --------------------------------------------------- | -------- | ------------------------- |

截图中的公司、职位、薪资、地点和职位描述均为合成内容，不对应真实公司或用户的求职记录。视觉原则见 [DESIGN-PHILOSOPHY.md](DESIGN-PHILOSOPHY.md)。
